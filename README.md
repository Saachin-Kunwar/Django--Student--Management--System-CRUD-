# 🎓 Django Student Management System (CRUD)

A clean, modular Django web application built to demonstrate full **Create, Read, Update, and Delete (CRUD)** functionality. Features a dynamic `ModelForm` with automated Bootstrap styling and robust error handling.

---

## ✨ Features

- **List Students:** View all registered students in a structured layout.
- **Add Student:** Create new student records with automatic form validation.
- **Edit Student:** Update existing student profiles seamlessly using instance-bound forms.
- **Delete Student:** Remove records cleanly with `get_object_or_404` safety checks.
- **Dynamic Form Styling:** Automatically applies Bootstrap `form-control` classes to all form fields.
